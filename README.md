# 📚 Web Scraping - Books Dataset

A Python web scraping project completed as part of my **CodeAlpha Internship**.

## 📌 Overview

This project uses **Requests, BeautifulSoup, and Pandas** to scrape book information from [Books to Scrape](https://books.toscrape.com/).

The scraper navigates through multiple pages, extracts book details, cleans the data, and creates a structured CSV dataset.

## 🎯 Objectives

- Practice web scraping with Python
- Understand HTML structure and navigation
- Extract relevant information from web pages
- Handle pagination
- Create a custom dataset
- Perform basic data validation and cleaning

## 📊 Data Collected

The final dataset contains **1,000 book records** with:

- Book Title
- Price
- Availability
- Rating
- Product URL
- Category
- Price in GBP

## 🛠️ Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas
